**Format**: `S_<YYYYMMDDTHHMMSSZ>_ARKV0`

**Implementation**:

```python
def generate_sid() -> str:
    utc_str = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
    return f"S_{utc_str}_ARKV0"
```

## Lessons Learned

### 1. Silent Failures Are Dangerous
The four-strike roadblock protocol was silently buffering errors. Added immediate stderr printing to `record_roadblock()` for visibility.

### 2. Self-Referential Checks Need Special Handling
Court Sweep checking its own bundle before completion required excluding the current bundle from uniformity checks.

### 3. Platform-Specific Path Issues
PowerShell's `Rename-Item` failed on certain paths. `Move-Item` proved more reliable for file renaming operations.

### 4. Command ID Synchronization
Interactive commands require careful tracking of command IDs. Always use the ID returned by the most recent `run_command` call.

### 5. Documentation Drift Prevention
Updating multiple docs simultaneously (CHANGELOG, IMPLEMENTATION_DELTA, ROUTE_LEGEND, TERMINAL_CANON) prevents documentation drift.
