## 4. LOCKED DEFINITIONS (DO NOT REINTERPRET)

These terms have caused drift or ambiguity before.

| Term | Operational Definition |
|------|------------------------|
| **Anchor** | A registered canonical source file with SHA256 hash, tracked in manifest |
| **Chunk** | A discrete unit of content from an anchor, stored in DB with locator |
| **Receipt** | A timestamped JSON witness of an action, optionally chain-linked |
| **SID** | Session ID in format `S_YYYYMMDDTHHMMSSZ_*`, required post-2025-12-25 |
| **Locator** | Precise reference to chunk origin (e.g., `pdf:page:0367:chars:466492-467136`) |
| **Bundle** | Collection of receipts + artifacts for a single session/operation |

**Explicitly NOT equivalent:**  
`Anchor` ? `Chunk` (anchor is source, chunk is derived unit)  
`Receipt` ? `Log` (receipt is cryptographic witness, log is diagnostic output)
