SCRIPTS FOLDER INVARIANTS
(CANONICAL ? VERSION 1.0)

PURPOSE
THE SCRIPTS FOLDER CONTAINS EXPLICIT, MANUAL ACTIONS
THAT CHANGE SYSTEM STATE IN CONTROLLED WAYS.

SCRIPTS ARE NEVER AUTOMATIC.
SCRIPTS ARE NEVER IMPLICIT.
SCRIPTS ARE NEVER IMPORTED AS SIDE EFFECTS.

THESE INVARIANTS DEFINE WHAT MAY NEVER BREAK.

--------------------------------------------------

1. SCRIPTS MUST BE EXPLICITLY RUN

INVARIANT:
NO SCRIPT IN THIS FOLDER MAY EXECUTE AUTOMATICALLY
DUE TO IMPORT OR PACKAGE INITIALIZATION.

ALL STATE-CHANGING BEHAVIOR MUST LIVE BEHIND:

IF __name__ == "__main__":

RATIONALE:
STATE CHANGES MUST BE CONSCIOUS.

--------------------------------------------------

2. SCRIPTS MAY CHANGE STRUCTURE, NOT MEANING

INVARIANT:
SCRIPTS MAY:
- CREATE DATABASES
- APPLY SCHEMAS
- REGISTER REFERENCES
- RUN READ-ONLY CHECKS

SCRIPTS MUST NOT:
- INTERPRET CONTENT
- MODIFY ANCHOR TEXT
- REWRITE CHUNKS
- ALTER MEANING

RATIONALE:
STRUCTURE ENABLES MEANING.
IT MUST NOT DECIDE IT.

--------------------------------------------------

3. SCRIPTS ARE SINGLE-PURPOSE

INVARIANT:
EACH SCRIPT MUST DO ONE THING ONLY.

EXAMPLES:
- init_db.py -> CREATE DATABASE
- sanity_check.py -> VERIFY COHERENCE

NO SCRIPT MAY COMBINE MULTIPLE RESPONSIBILITIES.

RATIONALE:
AMBIGUOUS ACTIONS DESTROY TRACEABILITY.

--------------------------------------------------

4. SCRIPTS ARE APPEND-ONLY IN EFFECT

INVARIANT:
SCRIPTS MUST NOT DELETE DATA BY DEFAULT.

DESTRUCTIVE ACTIONS REQUIRE:
- SEPARATE SCRIPT
- EXPLICIT NAMING
- HUMAN CONFIRMATION

RATIONALE:
FORGETTING MUST BE INTENTIONAL.

--------------------------------------------------

5. NO SCRIPT MAY SILENTLY FAIL

INVARIANT:
ALL ERRORS MUST:
- RAISE EXCEPTIONS
- PRINT CLEAR FAILURE REASONS
- HALT EXECUTION

NO SILENT FALLBACKS.
NO AUTO-REPAIR.
All Failures Must be Explicitly Shown and Handled.

RATIONALE:
SILENCE IS THE ENEMY OF TRUST.

--------------------------------------------------

6. SCRIPT OUTPUT IS DIAGNOSTIC, NOT COSMETIC

INVARIANT:
PRINT STATEMENTS MUST DESCRIBE:
- WHAT HAPPENED
- WHAT WAS CHANGED
- WHAT FAILED (IF APPLICABLE)

NO DECORATIVE LOGGING.

RATIONALE:
OUTPUT IS PART OF THE AUDIT TRAIL.

--------------------------------------------------

7. INVARIANTS ARE VERSIONED

INVARIANT:
UPDATES TO THIS FILE MUST NOT DELETE PRIOR VERSIONS.

OLD VERSIONS MUST BE MOVED TO:
scripts/archive/

RATIONALE:
LOGIC EVOLUTION MUST REMAIN TRACEABLE.

--------------------------------------------------

CLOSING PRINCIPLE

SCRIPTS ARE HANDS, NOT BRAINS.

THEY MAY BUILD THE SYSTEM,
BUT THEY MUST NEVER THINK FOR IT.

END OF SCRIPTS INVARIANTS ? V1.0
