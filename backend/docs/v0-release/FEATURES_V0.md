## Database Features

### Schema
- **anchors**: 31 entries (content sources)
- **chunks**: 3,446 entries (atomic content units)

### Capabilities
- [OK] **Foreign Key Constraints**: Chunks reference valid anchors
- [OK] **Indexed Queries**: Fast lookups by `chunk_id`, `anchor_id`, `import_session_id`
- [OK] **UTF-8 Storage**: Full Unicode support
- [OK] **Deterministic IDs**: Collision-proof chunk identification

### Query Examples
```sql
-- Count chunks by anchor
SELECT anchor_id, COUNT(*) FROM chunks GROUP BY anchor_id;

-- Find chunks by session
SELECT * FROM chunks WHERE import_session_id = 'S_20251225T075155Z_STATE_RECORD';

-- Verify orphans
SELECT COUNT(*) FROM chunks WHERE import_session_id IS NULL;
```

## Known Limitations

1. **Single-threaded**: No concurrent ingestion support
2. **SQLite-based**: Moderate workload only (not enterprise-scale)
3. **No semantic search**: Mechanical chunking only (embeddings not included in V0)
4. **Platform**: Tested primarily on Windows, cross-platform via Python
5. **Query interface**: Raw SQL only (no graphical query builder)
