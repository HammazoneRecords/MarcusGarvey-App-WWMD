## Technical Details

### Witness Epoch Validation Logic

**Flow**:
1. Parse epoch timestamp from `STATE_HISTORY.md`
2. Scan all lines for state transitions (pattern: `STATE_A -> STATE_B`)
3. Extract timestamp from each transition line
4. Compare timestamp to epoch: if after, check for SID marker
5. Report violations with line numbers, timestamps, transitions

**Implementation** ([`tools/verify_witness_epoch.py`](file:///c:/Users/Owner/Desktop/PROJECTS%20IN%20MOTION/ARK%20V0/solob%20wrapper%20ARK%20v0/solob-wrapper%20after%20abc%20real4plus/tools/verify_witness_epoch.py#L76-L107)):
```python
for idx, line in enumerate(lines, start=1):
    tsm = TS_RE.search(line)
    trm = TRANSITION_RE.search(line)
    if not (tsm and trm):
        continue
    
    ts_iso = tsm.group(1)
    ts_dt = iso_to_dt(ts_iso)
    
    if ts_dt <= epoch_dt:
        continue  # Pre-epoch, skip
    
    # Post-epoch: require SID
    if not SID_RE.search(line):
        violations.append({
            "line": idx,
            "timestamp": ts_iso,
            "transition": f"{trm.group(1)} -> {trm.group(2)}",
        })
```
