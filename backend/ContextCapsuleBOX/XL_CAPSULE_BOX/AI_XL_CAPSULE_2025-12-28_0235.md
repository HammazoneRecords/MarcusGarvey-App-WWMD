## Lessons Learned

### 1. Sankofa Forward Policy Works
- Recreated files from documentation rather than restoring corrupted versions
- Resulted in cleaner, better-documented implementations
- Archive documentation proved invaluable

### 2. Central Registry > Inline Headers
- YAML registry easier to manage than inline file headers
- Single source of truth for script states
- Easier for AI to scan and classify

### 3. HOLSTERED State Essential
- Files actively being modified need exemption from stamping
- Prevents false "UNSTAMPED" warnings
- Maintains governance without blocking development

### 4. Cryptographic Verification is Non-Negotiable
- SHA256 stamping caught drift immediately
- Provides tamper evidence
- Essential for Reality 6 (Guardian) compliance
