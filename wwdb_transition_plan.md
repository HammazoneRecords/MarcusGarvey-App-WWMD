1. Museum Logic (Non-Western, Non-Colonial)

Traditional museums do this:

Timeline → Object → Caption → Exit

Viewer = passive

Authority = institution

Your museum does this:

Node → State → Encounter

Viewer = participant

Authority = evidence + multiplicity

This aligns perfectly with WhirlwindDB.

2. The Room Model (Very Important)

Each person/node has one room, but that room has layers, not shelves.

A Room Is Composed Of:
A. Environmental State (always present)

Ambient sound (wind, city, ocean, printing press, crowd murmur)

Light tone (warm, harsh, flickering, calm)

Subtle motion (flags moving, papers rustling, machinery humming)

This sets the emotional frequency before content loads.

B. Evidence Artifacts (anchored to DB)

Pulled directly from WhirlwindDB:

Quotes → rendered as audio whispers, wall etchings, projected text

Documents → floating panels, scanned fragments

Photos → reframed as spatial objects (posters, newspapers, shadows)

Disputed claims → visually unstable objects (glitch, blur, fractured glass)

No essay walls.
Everything is felt first, read second.

C. Event Reconstructions (AI-assisted, not fictionalized)

This is where your idea becomes dangerous (in a good way).

Scenes are:

Clearly labeled as reconstructions

Generated from multiple sources

Adjustable by the user (confidence slider)

Example:

Black Star Line dock scene

UNIA meeting hall

FBI surveillance room (yes — include the watchers)

User can toggle:

“Source-strict mode” (only what is directly evidenced)

“Interpretive mode” (AI fills gaps but marks them)

This keeps integrity.

D. Perspective Switch (this is the killer feature)

User can switch viewpoint:

The figure

The crowd

The opposition

The institution watching

Same room.
Different truth angles.

This alone separates you from every museum on earth.
